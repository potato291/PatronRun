## 🎮 Інструкція користувача (User Manual)

### Мета гри
Дістатися фінішного об'єкта в кінці рівня, не втративши життя. По дорозі потрібно збирати монетки для підвищення рахунку.

### Управління
Клавіатура (PC):
* **⬅️ / ➡️** (або **A / D**) — Рух вліво та вправо.
* **Space (Пробіл)** — Стрибок.
* **Esc** — Пауза / Виклик меню.

### Ігрові механіки
* **🪙 Монетки:** Додають +1 до загального рахунку (відображається зверху).
* **⚠️ Перешкоди:** Шипи та прірви миттєво перезапускають рівень.
* **🏁 Фініш:** При досягненні кінця рівня гравець перемагає.

## 🚀 Як запустити гру (Installation)

### Спосіб 1: Запуск готової версії (Build)
*Для тих, хто хоче просто пограти.*
1.  Завантажте архів з останньою версією гри (папка `Build`).
2.  Розпакуйте архів у будь-яке місце на комп'ютері.
3.  Запустіть файл **`PatronGame.exe`**.
    > **Важливо:** Не витягуйте `.exe` файл із папки! Він повинен знаходитися поруч із папкою `_Data`.

### Спосіб 2: Відкриття проєкту в Unity (Source Code)
*Для розробників та перевірки коду.*
1.  Переконайтеся, що у вас встановлено **Unity Hub** та версія Unity **6 (або ваша версія)**.
2.  Клонуйте цей репозиторій:
    ```bash
    git clone [https://github.com/ВАШ_НІКНЕЙМ/PatronRun.git](https://github.com/ВАШ_НІКНЕЙМ/PatronRun.git)
    ```
3.  Відкрийте Unity Hub, натисніть **Add** (Додати) та оберіть папку з проєктом.
4.  Запустіть проєкт. Для старту гри відкрийте сцену: `Assets/Scenes/Menu`.
